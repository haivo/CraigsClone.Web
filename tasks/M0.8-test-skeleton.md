# M0.8 — Test skeleton: three folders, two fixtures, three smoke tests

**Goal:** From here on, every task can add unit, integration, and E2E tests without any more setup. Read [01-testing-approach.md](01-testing-approach.md) first.

**Steps**

1. Add packages to the test project:

   ```powershell
   dotnet add tests/CraigsClone.Tests package Microsoft.AspNetCore.Mvc.Testing
   dotnet add tests/CraigsClone.Tests package Microsoft.Playwright
   ```

   (`Testcontainers.PostgreSql` was already added in M0.3.)

2. Make `Program` visible to tests. At the very bottom of `src/CraigsClone.Web/Program.cs` add:

   ```csharp
   public partial class Program { }
   ```

3. Delete `tests/CraigsClone.Tests/UnitTest1.cs`. Create folders `Unit/`, `Integration/`, `E2E/`.

4. Create `tests/CraigsClone.Tests/Integration/PostgresFixture.cs` (it grows in M1.2 and M1.5):

   ```csharp
   using Testcontainers.PostgreSql;

   public class PostgresFixture : IAsyncLifetime
   {
       private readonly PostgreSqlContainer _pg = new PostgreSqlBuilder("postgres:16").Build();
       public string ConnectionString => _pg.GetConnectionString();

       public Task InitializeAsync() => _pg.StartAsync();
       public Task DisposeAsync() => _pg.DisposeAsync().AsTask();
   }

   [CollectionDefinition("postgres")]
   public class PostgresCollection : ICollectionFixture<PostgresFixture>;
   ```

5. Create `tests/CraigsClone.Tests/E2E/WebAppFixture.cs`:

   ```csharp
   using Microsoft.AspNetCore.Hosting.Server;
   using Microsoft.AspNetCore.Hosting.Server.Features;
   using Microsoft.AspNetCore.Mvc.Testing;
   using Microsoft.Extensions.DependencyInjection;
   using Microsoft.Playwright;
   using Testcontainers.PostgreSql;

   public class WebAppFixture : IAsyncLifetime
   {
       private readonly PostgreSqlContainer _pg = new PostgreSqlBuilder("postgres:16").Build();
       private WebApplicationFactory<Program> _factory = null!;
       private IPlaywright _pw = null!;

       public IBrowser Browser { get; private set; } = null!;
       public string BaseUrl { get; private set; } = "";
       public IServiceProvider Services => _factory.Services;
       public HttpClient CreateClient() => new() { BaseAddress = new Uri(BaseUrl + "/") };

       public async Task InitializeAsync()
       {
           await _pg.StartAsync();
           _factory = new WebApplicationFactory<Program>().WithWebHostBuilder(b =>
               b.UseSetting("ConnectionStrings:Default", _pg.GetConnectionString()));
           _factory.UseKestrel();      // real port, so a browser can reach it (.NET 10 API)
           _factory.StartServer();

           // There is no ServerAddress property. Ask Kestrel directly which address it bound.
           var addresses = _factory.Services.GetRequiredService<IServer>()
               .Features.Get<IServerAddressesFeature>()?.Addresses
               ?? throw new InvalidOperationException("Kestrel reported no addresses.");
           BaseUrl = addresses.First(a => a.StartsWith("http://")).TrimEnd('/');

           _pw = await Playwright.CreateAsync();
           Browser = await _pw.Chromium.LaunchAsync();
       }

       public async Task DisposeAsync()
       {
           await Browser.DisposeAsync();
           _pw.Dispose();
           await _factory.DisposeAsync();
           await _pg.DisposeAsync();
       }
   }

   [CollectionDefinition("app")]
   public class AppCollection : ICollectionFixture<WebAppFixture>;
   ```

6. Build, then install the browser once:

   ```powershell
   dotnet build
   powershell tests/CraigsClone.Tests/bin/Debug/net10.0/playwright.ps1 install chromium
   ```

## Tests

**Unit** — `Unit/SanityTests.cs`: one test, `Assert.Equal(2, 1 + 1)`. It proves the runner and the `Category=Unit` filter work.

**Integration** — `Integration/PostgresFixtureTests.cs`, `[Collection("postgres")]`: open an `NpgsqlConnection` with `fixture.ConnectionString`, run `select 1`, assert it returns 1. Proves Docker and Testcontainers work on this machine.

**End-to-end** — `E2E/HomePageTests.cs`, `[Collection("app")]`:

```csharp
[Fact]
public async Task HomePage_Loads()
{
    var page = await fixture.Browser.NewPageAsync();
    try
    {
        var resp = await page.GotoAsync(fixture.BaseUrl + "/");
        Assert.True(resp!.Ok);
        Assert.Contains("CraigsClone", await page.TitleAsync());
    }
    finally { await page.CloseAsync(); }
}
```

Proves the app starts on a real port and a browser can load it.
