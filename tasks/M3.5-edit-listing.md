# M3.5 — Edit a listing

**Goal:** `/listing/5/edit` shows the same form, prefilled. Saving updates the ad.

**Steps**

In `ListingsController`:

```csharp
[HttpGet("listing/{id:int}/edit")]
public async Task<IActionResult> Edit(int id)

[HttpPost("listing/{id:int}/edit")]
public async Task<IActionResult> Edit(int id, ListingFormVm form)
```

- GET: `GetAsync(id)`; 404 if null. Copy the entity into a `ListingFormVm`, fill select lists, return the view.
- POST: if invalid, refill lists and redisplay. Otherwise `UpdateAsync(id, form)`; if it returns false, 404. Set `TempData["Success"] = "Saved."` and redirect to Details.

Put "entity → form" in a public static `ListingFormVm.From(Listing)` so it can be unit-tested.

View `Views/Listings/Edit.cshtml` — heading "edit ad", the same `<form method="post">` with the `_ListingForm` partial, and a submit button with text `save`.

Add an `edit` link on the Details page pointing to `/listing/{id}/edit`.

**Files**

- `src/CraigsClone.Web/Controllers/ListingsController.cs` (edited)
- `src/CraigsClone.Web/ViewModels/ListingFormVm.cs` (edited, `From` method)
- `src/CraigsClone.Web/Views/Listings/Edit.cshtml` (new)

## Tests

**Unit** — `Unit/ViewModels/ListingFormVmFromTests.cs`: `ListingFormVm.From(listing)` copies title, description, price, city id, category id, neighborhood, and email. Round trip: `From` then `ListingService.Apply` onto a fresh `Listing` gives back equal fields.

**Integration** — `Integration/Pages/EditPageTests.cs`, `[Collection("app")]`:

- Insert a listing via `fixture.Services`, `GET /listing/{id}/edit` → 200, the title input's `value` attribute contains the title, and the correct city option is `selected`.
- `GET /listing/999999/edit` → 404.
- `GET /listing/{id}` body contains `href="/listing/{id}/edit"`.

**End-to-end** — `E2E/EditListingTests.cs`, `[Collection("app")]`:

- Insert a listing via `fixture.Services`. Open `/listing/{id}`, click `edit`, expect the title input to already contain the title. Clear it, type a new unique title, click `save`. Expect URL `/listing/{id}` and the heading to equal the new title.
- Read the row back through `fixture.Services` and assert `UpdatedAt > CreatedAt`.
