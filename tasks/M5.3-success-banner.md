# M5.3 — Success banner

**Goal:** After posting, editing, or deleting, the next page shows a one-line message like "Your ad is posted."

**Steps**

Create `Views/Shared/_Alert.cshtml`:

```html
@if (TempData["Success"] is string msg)
{
    <div class="alert" role="status">@msg</div>
}
```

In `_Layout.cshtml`, render it at the top of `<main>`:

```html
<main>
  <partial name="_Alert" />
  @RenderBody()
</main>
```

The controllers from M3.4 to M3.6 already set `TempData["Success"]`. `TempData` survives exactly one redirect, then clears itself.

**Files**

- `src/CraigsClone.Web/Views/Shared/_Alert.cshtml` (new)
- `src/CraigsClone.Web/Views/Shared/_Layout.cshtml` (edited)

## Tests

**Unit** — none. A conditional in Razor.

**Integration** — add to `Integration/Pages/LayoutTests.cs`: `GET /` body does **not** contain `class="alert"`. Pins that the banner is absent when nothing happened, so a stray always-visible box gets caught.

The positive case needs a real POST with a token, which is easier in the browser.

**End-to-end** — `E2E/BannerTests.cs`, `[Collection("app")]`:

- Post an ad through the form (reuse the M3.4 happy-path steps). On the resulting details page expect `Your ad is posted.` to be visible. Reload the page. Expect it **not** to be visible.
- Edit the ad and save. Expect `Saved.` visible.
- Delete the ad (accept the dialog). Expect `Ad deleted.` visible on the category page.

**Done when:** Tests above are green.
