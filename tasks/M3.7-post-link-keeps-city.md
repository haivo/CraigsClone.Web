# M3.7 — "post" link remembers the city

**Goal:** When you're browsing Austin and click "post", the city dropdown is already set to Austin.

**Steps**

In `_Layout.cshtml`, change the post link so that, when `ViewData["CitySlug"]` is set, it becomes `/post?city=austin`:

```html
<a href="/post@(ViewData["CitySlug"] is string s ? "?city=" + s : "")">post</a>
```

The GET `Create` action from M3.4 already reads the `city` query parameter and preselects it.

**Files**

- `src/CraigsClone.Web/Views/Shared/_Layout.cshtml` (edited)

## Tests

**Unit** — none. One Razor expression.

**Integration** — add to `Integration/Pages/LayoutTests.cs`:

- `GET /` body contains `href="/post"` and does not contain `href="/post?city=`.
- `GET /austin/furniture` body contains `href="/post?city=austin"`.
- `GET /listing/{id}` (a listing in Austin) body contains `href="/post?city=austin"`.

**End-to-end** — add to `E2E/PostListingTests.cs`:

- Open `/austin/furniture`, click `post`, expect URL `/post?city=austin`, and expect the `CityId` select's selected option text to be `Austin` (`page.Locator("select[name=CityId] option:checked")`).

**Done when:** Tests above are green.
