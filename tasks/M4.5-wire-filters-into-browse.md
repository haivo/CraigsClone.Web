# M4.5 — Wire filters into the category browse page

**Goal:** `/austin/furniture?q=chair&max=100&page=2` works end to end.

**Steps**

1. Add `public required SearchFilterVm Filter { get; init; }` to `ListingIndexVm`.
2. Change the `Index` action signature to:

   ```csharp
   [HttpGet("{citySlug}/{categorySlug}")]
   public async Task<IActionResult> Index(string citySlug, string categorySlug, SearchFilterVm filter)
   ```

   MVC fills `filter` from the query string automatically.
3. Call `BrowseAsync(city.Id, category.Id, filter)` and pass `filter` into the view model.
4. In `Views/Listings/Index.cshtml`, render `_SearchForm` above the list and `_Pager` below it. Show "N results" and, when there are none, `nothing found`.
