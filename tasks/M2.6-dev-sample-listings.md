# M2.6 — Sample listings for development

**Goal:** About 30 fake ads so the pages aren't empty while you build. Only in Development, never in production.

**Steps**

Create `src/CraigsClone.Web/Data/DevSeeder.cs`. Like `DbSeeder`, expose the data as a static list so it can be checked without a database:

```csharp

{
    // (citySlug, categorySlug, title, price, daysAgo)
    public static readonly IReadOnlyList<(string City, string Category, string Title, decimal? Price, int DaysAgo)> Samples = [ ... ];

    public static async Task SeedAsync(AppDbContext db)
    {
        if (await db.Listings.AnyAsync()) return;   // only seeds once
        // resolve city/category ids by slug, create Listings with
        // CreatedAt = UpdatedAt = DateTime.UtcNow.AddDays(-DaysAgo), save
    }
}
```

Use around 30 samples across several cities and categories. Vary the prices and leave a few `null`.

In `Program.cs`, inside the existing `IsDevelopment()` block from M1.6, add after `DbSeeder`:

```csharp
await DevSeeder.SeedAsync(db);
```

**Files**

## Tests

**Unit** — `Unit/Data/DevSeederDataTests.cs`, reading `DevSeeder.Samples`:

- At least 30 samples.
- Every `City` slug exists in `DbSeeder.Cities`; every `Category` slug exists in `DbSeeder.Categories`. Catches typos before they become a runtime crash.
- At least one sample has a null price and at least one has a price (so both display paths get exercised).
- All titles are 120 characters or fewer.

**Integration** — `Integration/Data/DevSeederTests.cs`, `[Collection("postgres")]`:

- On a context with no listings: run `SeedAsync` twice, count equals `Samples.Count` (not double).
- Every seeded listing has `CreatedAt.Kind == DateTimeKind.Utc` after reading back.

**End-to-end** — add to `E2E/BrowseTests.cs`: open `/austin/furniture` (pick a city/category you know has samples) and expect at least one listing row to be visible without creating any data first. This is the "pages aren't empty" check.

**Done when:** After `dotnet run`, you can click home → Austin → furniture → an ad and see its details; tests are green. This is the M2 finish line.
