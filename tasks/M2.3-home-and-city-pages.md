# M2.3 — Home page and city page

**Goal:** `/` shows a list of cities and the category groups. `/austin` shows the groups for Austin with links into each category.

**Steps**

`Controllers/HomeController.cs` — two actions, both reading from `AppDbContext`:

```csharp
[HttpGet("")]
public async Task<IActionResult> Index()

[HttpGet("{citySlug}")]
public async Task<IActionResult> City(string citySlug)
```

- `Index` loads all cities and all categories, groups categories by `Group`, returns `HomeVm`.
- `City` looks up the city by slug. If not found, `return NotFound();`. Otherwise returns `CityVm`.

Put the "group categories by Group, in enum order" logic in a small static helper `CategoryGrouping.Group(IEnumerable<Category>)` in `ViewModels/CategoryGrouping.cs`, so it can be unit-tested and shared by both actions.

Views:

- `Views/Shared/_CategoryGroups.cshtml` — a partial that takes the groups and an optional city slug. For each group prints a heading and a list of category links to `/{citySlug}/{categorySlug}`. (On the home page with no city chosen, print the names without links.)
- `Views/Home/Index.cshtml` — list of city links to `/{citySlug}`, then the partial.
- `Views/Home/City.cshtml` — city name as heading, then the partial with links.
