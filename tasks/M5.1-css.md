# M5.1 — Craigslist-flavoured CSS

**Goal:** Deliberately plain styling that reads well on a phone.

**Steps**

Replace `wwwroot/css/site.css`. Aim for roughly:

- `body`: system sans-serif font, 15px, dark gray text on white, `margin: 0`, `padding: 0 16px`.
- `main`: `max-width: 960px; margin: 0 auto`.
- `header`: a thin bottom border, links spaced out.
- links: blue (`#00e` style), visited purple, underline on hover only.
- `_ListingRow`: one line per ad, date in gray on the left, price on the right, wraps on narrow screens.
- forms: inputs full width on narrow screens, labels above inputs, validation errors in red.
- `_Pager`: inline links with spacing, current page bold.
- `.alert`: light yellow background (used by M5.3).

No framework, no build step, under about 100 lines.

**Files**

- `src/CraigsClone.Web/wwwroot/css/site.css` (edited)

## Tests

**Unit** — none. CSS has no logic.

**Integration** — `Integration/Pages/StaticFilesTests.cs`, `[Collection("app")]`: `GET /css/site.css` → 200, content type starts with `text/css`, body length > 0 and contains `main`. Catches a renamed or missing file, which would silently leave the site unstyled.

**End-to-end** — `E2E/ResponsiveTests.cs`, `[Collection("app")]`. Playwright can measure layout:

```csharp
await page.SetViewportSizeAsync(400, 800);
await page.GotoAsync(fixture.BaseUrl + "/austin/furniture");
var overflow = await page.EvaluateAsync<bool>(
    "() => document.documentElement.scrollWidth > document.documentElement.clientWidth");
Assert.False(overflow);
```

Run it for `/`, `/austin/furniture`, `/post`, and a details page. This is the "no horizontal scrollbar at phone width" check made automatic.

**Done when:** Tests above are green and the site looks deliberately plain.
