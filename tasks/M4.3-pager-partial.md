# M4.3 — Pager partial

**Goal:** "prev 1 2 3 next" links under a results list that keep the current filters.

**Steps**

Create `ViewModels/PagerVm.cs`:

```csharp
public record PagerVm(int Page, int TotalPages, SearchFilterVm Filter)
{
    // Which page numbers to show: up to 3 on each side of the current page.
    public IEnumerable<int> Range()
    {
        var from = Math.Max(1, Page - 3);
        var to = Math.Min(TotalPages, Page + 3);
        for (var i = from; i <= to; i++) yield return i;
    }

    public string Href(int page) =>
        QueryHelpers.AddQueryString("", Filter.ToRouteValues(page));
}
```

Create `Views/Shared/_Pager.cshtml` with `@model PagerVm`:

- If `TotalPages <= 1`, render nothing.
- `prev` links to `Href(Page - 1)` when `Page > 1`.
- Each number in `Range()`, the current one as plain text with class `current`, others linked.
- `next` links to `Href(Page + 1)` when `Page < TotalPages`.

Because the href is just `?q=bike&page=2` with no path, the browser resolves it against the current page. `QueryHelpers` is in `Microsoft.AspNetCore.WebUtilities`.

**Files**

- `src/CraigsClone.Web/ViewModels/PagerVm.cs` (new)
- `src/CraigsClone.Web/Views/Shared/_Pager.cshtml` (new)

## Tests

**Unit** — `Unit/ViewModels/PagerVmTests.cs`:

- `Range()` for page 1 of 10 → 1..4; page 5 of 10 → 2..8; page 10 of 10 → 7..10; page 1 of 1 → just 1.
- `Href(2)` with `Q = "bike"` → `?q=bike&page=2`; `Href(1)` → `?q=bike` (no `page=1`).
- `Href(2)` with an empty filter → `?page=2`.

**Integration** — `Integration/Pages/PagerTests.cs`, `[Collection("app")]`, after M4.5:

- Insert 25 listings in a city/category no sample data uses (for example `denver` / `lost-found`). `GET /denver/lost-found` body contains `href="?page=2"` and text `next`.
- Insert 5 in another empty combo. Its page contains neither `page=2` nor `next`.
- `GET /denver/lost-found?q=x&page=2` (where `x` matches your rows) contains `href="?q=x"` for the prev link, proving filters are preserved.

**End-to-end** — `E2E/PagingTests.cs`, `[Collection("app")]`, after M4.5:

- With the 25-row setup, open the category page, click `next`, expect URL to contain `page=2`, expect exactly 5 listing rows visible, and `next` not visible.
