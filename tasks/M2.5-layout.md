# M2.5 — Layout and a placeholder stylesheet

**Goal:** Every page shares a simple header: site name linking home, and a "post" link.

**Steps**

Rewrite `Views/Shared/_Layout.cshtml` so the body is:

```html
<header>
  <a href="/">CraigsClone</a>
  @if (ViewData["CitySlug"] is string slug) { <a href="/@slug">@ViewData["CityName"]</a> }
  <a href="/post">post</a>
</header>
<main>@RenderBody()</main>
```

Set `<title>` to `@ViewData["Title"] - CraigsClone`.

In the controllers, set `ViewData["CitySlug"]` and `ViewData["CityName"]` whenever a page belongs to a city (City, Index, Details).

Replace `wwwroot/css/site.css` with a few lines: a max-width on `main`, a readable font, and some spacing. The real styling comes in M5.1.

**Files**

- `src/CraigsClone.Web/Views/Shared/_Layout.cshtml` (edited)
- `src/CraigsClone.Web/wwwroot/css/site.css` (edited)

## Tests

**Integration** — `Integration/Pages/LayoutTests.cs`, `[Collection("app")]`:

- `GET /` body contains `<header>` and `href="/post"`, and does **not** contain `bootstrap`.
- `GET /austin/furniture` body contains `href="/austin"` inside the header (the current-city link).
- `GET /css/site.css` → 200 with content type `text/css`.
