# M0.2 — Create the solution and the two projects

**Goal:** One solution containing a web project and a test project.

**Steps**

```powershell
dotnet new sln -n CraigsClone
dotnet new mvc -n CraigsClone.Web -o src/CraigsClone.Web -f net10.0
dotnet new xunit -n CraigsClone.Tests -o tests/CraigsClone.Tests -f net10.0
dotnet sln add src/CraigsClone.Web tests/CraigsClone.Tests
dotnet add tests/CraigsClone.Tests reference src/CraigsClone.Web
dotnet build
```

**Files**

- `CraigsClone.slnx` (new). .NET 10 creates the newer XML solution format by default; the extension is `.slnx`, not `.sln`, and all `dotnet` commands accept it.
- `src/CraigsClone.Web/` (new, whole MVC template)
- `tests/CraigsClone.Tests/` (new, xUnit template)
