# M5.5 — README

**Goal:** A stranger can clone the repo and run the site by following the README alone.

**Steps**

Write `README.md` with these sections, in this order:

1. **What it is** — two sentences. Link to `PLAN.md`.
2. **Prerequisites** — .NET 10 SDK, Docker Desktop. Nothing else.
3. **Run it**
   ```powershell
   docker compose up -d
   dotnet run --project src/CraigsClone.Web
   ```
   then open the URL printed in the console. Mention that tables and seed data are created automatically on first run.
4. **Run the tests** — the three categories and `.\test.ps1`, the one-time Playwright browser install, and that Docker must be running for integration and E2E.
5. **Look at the database** — `docker compose exec db psql -U postgres craigsclone`.
6. **Configuration** — the `ConnectionStrings__Default` environment variable and `.env.example`.
7. **Warning** — there are no user accounts, so anyone can edit or delete any ad. Localhost only; do not deploy as-is.
8. **What's next** — copy the stretch list from PLAN.md section 8.

**Files**

- `README.md` (edited)

## Tests

Prose can't be unit-tested, but the commands in it can be checked.

**Unit** — none.

**Integration** — none automated. Manual: copy each command out of the README and run it exactly as written. If any needs editing to work, the README is wrong.

**End-to-end** — M5.6 is this task's end-to-end test: a fresh clone, driven only by the README.

**Done when:** You can hand the README to someone who's never seen the project and they get it running.
