# M0.7 — Remove template extras and switch to attribute routing

**Goal:** A bare app with no Bootstrap, no jQuery, no Privacy page, and only the routes we write ourselves.

**Why:** See [00-before-you-start.md](00-before-you-start.md), points 1 and 9.

**Steps**

1. Delete these:
   - `src/CraigsClone.Web/wwwroot/lib/` (the whole folder)
   - `src/CraigsClone.Web/Views/Home/Privacy.cshtml`
   - `src/CraigsClone.Web/Views/Shared/_ValidationScriptsPartial.cshtml`
2. In `Controllers/HomeController.cs`, delete the `Privacy` action.
3. In `Views/Shared/_Layout.cshtml`, remove the `<link>` to bootstrap and the `<script>` tags for jquery and bootstrap. Keep the link to `~/css/site.css`.
4. In `Program.cs`, replace

   ```csharp
   app.MapControllerRoute(
       name: "default",
       pattern: "{controller=Home}/{action=Index}/{id?}");
   ```

   with

   ```csharp
   app.MapControllers();
   ```

5. Put a route on the `Index` action of `HomeController` so the home page still has one:

   ```csharp
   [HttpGet("")]
   public IActionResult Index() => View();
   ```

**Files**

- `src/CraigsClone.Web/Program.cs` (edited)
- `src/CraigsClone.Web/Controllers/HomeController.cs` (edited)
- `src/CraigsClone.Web/Views/Shared/_Layout.cshtml` (edited)
- `src/CraigsClone.Web/Views/Home/Privacy.cshtml` (deleted)
- `src/CraigsClone.Web/Views/Shared/_ValidationScriptsPartial.cshtml` (deleted)
- `src/CraigsClone.Web/wwwroot/lib/` (deleted)

## Tests

**Unit** — `Unit/HomeControllerTests.cs`: `new HomeController().Index()` returns a `ViewResult`. Small, but it proves the action exists and needs no dependencies. (M2.3 changes this when the action starts reading the database.)

**Integration** — `Integration/RoutingTests.cs`, `[Collection("app")]`, using `fixture.CreateClient()`:

- `GET /` → 200
- `GET /Home/Privacy` → 404 (page deleted)
- `GET /Home/Index` → 404 (conventional route is gone; only `/` works)
- `GET /lib/bootstrap/dist/css/bootstrap.min.css` → 404 (folder deleted)

**End-to-end** — extend `E2E/HomePageTests.cs`: load `/`, collect failed network requests via `page.RequestFailed` and responses with status ≥ 400 via `page.Response`, and assert there are none. This catches a leftover `<script src>` to a deleted file.

**Done when:** All tests above pass and `dotnet run` shows an unstyled home page.
