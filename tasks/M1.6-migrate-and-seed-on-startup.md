# M1.6 — Apply migrations and seed on startup

**Goal:** When the app starts in Development, it creates or updates the tables and inserts the seed rows. No manual `dotnet ef database update` needed.

**Steps**

In `src/CraigsClone.Web/Program.cs`, after `var app = builder.Build();` add:

```csharp
if (app.Environment.IsDevelopment())
{
    using var scope = app.Services.CreateScope();
    var db = scope.ServiceProvider.GetRequiredService<AppDbContext>();
    await db.Database.MigrateAsync();
    await DbSeeder.SeedAsync(db);
}
```

Then run it:

```powershell
docker compose up -d
dotnet run --project src/CraigsClone.Web
```

Check the database (there is no local psql, so go through the container):

```powershell
docker compose exec db psql -U postgres craigsclone -c '\dt'
docker compose exec db psql -U postgres craigsclone -c 'select count(*) from "Categories"'
```

**Files**

- `src/CraigsClone.Web/Program.cs` (edited)
