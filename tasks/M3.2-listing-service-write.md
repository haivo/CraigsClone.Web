# M3.2 — ListingService (write side)

**Goal:** Create, update, and delete listings through the service. The service is the only place that sets timestamps.

**Steps**

Add to `IListingService`:

```csharp
Task<Listing> CreateAsync(ListingFormVm form);
Task<bool> UpdateAsync(int id, ListingFormVm form);   // false if not found
Task<bool> DeleteAsync(int id);                       // false if not found
```

Implement in `ListingService`:

- `CreateAsync`: new `Listing`, apply the form, set `CreatedAt = UpdatedAt = DateTime.UtcNow`, add, save, return it.
- `UpdateAsync`: find by id (return false if null), apply the form, set `UpdatedAt = DateTime.UtcNow`, save, return true.
- `DeleteAsync`: find by id (return false if null), remove, save, return true.

Put "apply the form" in one public static method so both paths share it and it can be unit-tested:

```csharp
public static void Apply(ListingFormVm form, Listing target)
{
    target.Title = form.Title.Trim();
    target.Description = form.Description.Trim();
    target.Price = form.Price;
    target.CityId = form.CityId!.Value;
    target.CategoryId = form.CategoryId!.Value;
    target.Neighborhood = string.IsNullOrWhiteSpace(form.Neighborhood) ? null : form.Neighborhood.Trim();
    target.ContactEmail = form.ContactEmail.Trim();
}
```

**Important:** always `DateTime.UtcNow`, never `DateTime.Now`. Postgres will reject local times. See [00-before-you-start.md](00-before-you-start.md), point 4.

## Tests

**Unit** — `Unit/Services/ListingServiceApplyTests.cs`, testing `Apply` only:

- every field is copied
- title and email are trimmed
- whitespace-only neighborhood becomes null
- `CreatedAt`, `UpdatedAt`, and `Id` on the target are untouched

**Integration** — `Integration/Services/ListingServiceWriteTests.cs`, `[Collection("postgres")]`:

- `CreateAsync` → the row exists, `Id > 0`, `CreatedAt == UpdatedAt`, `CreatedAt.Kind == Utc`, `CreatedAt` within a few seconds of now.
- `UpdateAsync` with a changed title → reading back shows the new title and `UpdatedAt > CreatedAt`. (Add a short `Task.Delay(10)` between create and update so the clocks differ.)
- `UpdateAsync(999999, form)` → false.
- `DeleteAsync` → `GetAsync` returns null afterwards.
- `DeleteAsync(999999)` → false.
