# M4.4 — Search form partial

**Goal:** A small GET form at the top of results pages: keyword, min price, max price, sort, and a "search" button.

**Steps**

Create `Views/Shared/_SearchForm.cshtml` with `@model SearchFilterVm`:

```html
<form method="get" class="search">
  <input name="q" value="@Model.Q" placeholder="search" aria-label="search" />
  <input name="min" type="number" step="0.01" value="@Model.Min" placeholder="min $" aria-label="min price" />
  <input name="max" type="number" step="0.01" value="@Model.Max" placeholder="max $" aria-label="max price" />
  <select name="sort" aria-label="sort">
    <option value="newest" selected="@(Model.Sort == ListingSort.Newest)">newest</option>
    <option value="priceasc" selected="@(Model.Sort == ListingSort.PriceAsc)">price: low to high</option>
    <option value="pricedesc" selected="@(Model.Sort == ListingSort.PriceDesc)">price: high to low</option>
  </select>
  @if (Model.City is not null) { <input type="hidden" name="city" value="@Model.City" /> }
  @if (Model.Category is not null) { <input type="hidden" name="category" value="@Model.Category" /> }
  <button type="submit">search</button>
</form>
```

`method="get"` means submitting just changes the query string on the current URL. No `page` field, so a new search always starts on page 1. The `aria-label`s give the E2E tests something stable to find.
