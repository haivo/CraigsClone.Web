# M2.4 — Category browse page and listing details page

**Goal:** `/austin/furniture` lists ads newest first. `/listing/5` shows one ad.

**Steps**

Create `Controllers/ListingsController.cs` with `AppDbContext` and `IListingService` injected:

```csharp
[HttpGet("{citySlug}/{categorySlug}")]
public async Task<IActionResult> Index(string citySlug, string categorySlug, int page = 1)

[HttpGet("listing/{id:int}")]
public async Task<IActionResult> Details(int id)
```

- `Index`: look up the city and category by slug. If either is missing, `NotFound()`. Call `BrowseAsync`, return `ListingIndexVm`.
- `Details`: call `GetAsync(id)`. If null, `NotFound()`. Return the listing.

Create a tiny display helper `ViewModels/Display.cs`:

```csharp
public static class Display
{
    public static string Price(decimal? p) => p is null ? "—" : $"${p:N0}";
    public static string Posted(DateTime utc) => utc.ToString("MMM d");
}
```

Views:

- `Views/Shared/_ListingRow.cshtml` — a partial that takes one `Listing` and prints: `Display.Posted(CreatedAt)`, title (linked to `/listing/{id}`), `Display.Price(Price)`, neighborhood if any.
- `Views/Listings/Index.cshtml` — heading "{category} in {city}", then a loop rendering `_ListingRow` for each item. Show "no listings yet" if empty.
- `Views/Listings/Details.cshtml` — title, price, posted date, city / neighborhood, description, contact email.
