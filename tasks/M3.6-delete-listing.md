# M3.6 — Delete a listing

**Goal:** A "delete" button on the details page that asks "are you sure?" and then removes the ad.

**Steps**

In `ListingsController`:

```csharp
[HttpPost("listing/{id:int}/delete")]
public async Task<IActionResult> Delete(int id)
```

- Load the listing first so you know its city and category slugs (you need them for the redirect).
- `DeleteAsync(id)`; 404 if false.
- `TempData["Success"] = "Ad deleted."`, then redirect to `/{citySlug}/{categorySlug}`.

On `Views/Listings/Details.cshtml` add:

```html
<form method="post" action="/listing/@Model.Id/delete" asp-antiforgery="true" onsubmit="return confirm('Delete this ad?');">
  <button type="submit">delete</button>
</form>
```

Delete is a POST (not a GET link) so a crawler or a prefetch can't accidentally remove ads. `asp-antiforgery="true"` is required here. When a form has a hand-written `action` attribute, the form tag helper does NOT add the token on its own, and the global filter from M3.3 answers the POST with 400. Forms without an `action` (post, edit) get the token automatically.

That inline `confirm` is the whole JavaScript for this project. No `site.js` needed.

**Files**

## Tests

**Unit** — none. The action is a lookup, a service call, and a redirect; the integration and E2E tests below cover it end to end.

**Integration** — `Integration/Pages/DeletePageTests.cs`, `[Collection("app")]`:

- `GET /listing/{id}` body contains `action="/listing/{id}/delete"` and `method="post"`. Pins that delete is a POST form, not a link.
- `GET /listing/{id}/delete` → 404 or 405 (there is no GET route). Pins that a link can't delete.
- `POST /listing/{id}/delete` without token → 400 (already in M3.3's tests; keep it there).

**End-to-end** — `E2E/DeleteListingTests.cs`, `[Collection("app")]`. Playwright dismisses dialogs by default, so the test must handle it:

- **Confirm:** insert a listing in Austin/furniture via `fixture.Services`. Open `/listing/{id}`, register `page.Dialog += (_, d) => d.AcceptAsync()`, click `delete`. Expect URL to end with `/austin/furniture` and the title **not** to be visible. `GET /listing/{id}` via `CreateClient()` → 404.
- **Cancel:** same setup, but `d.DismissAsync()`. Expect URL still `/listing/{id}` and the title still visible.

**Done when:** All tests above are green. This is the M3 finish line.
