# M0.1 — Start the git repo and README

**Goal:** Turn the folder into a git repository with a proper ignore file and a placeholder README.

**Steps**

```powershell
cd C:\Data\sources\CraigsClone
git init
dotnet new gitignore
```

Then create `README.md` with just a title and one sentence, for example:

```
# CraigsClone
A Craigslist-style classifieds site built with ASP.NET Core MVC and PostgreSQL. Learning project.
```

Commit:

```powershell
git add .
git commit -m "Initial commit: plan and tasks"
```

**Files**

- `.gitignore` (new, generated)
- `README.md` (new)
