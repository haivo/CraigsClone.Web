# M0.4 — Install the dotnet-ef tool

**Goal:** Get the command-line tool that creates database migrations.

Do this *after* M0.3, because the tool's major version must match the EF Core version the packages pulled in (10.x).

**Steps**

```powershell
dotnet tool install -g dotnet-ef --version "10.*"
dotnet ef --version
```

If it's already installed at a different version:

```powershell
dotnet tool update -g dotnet-ef --version "10.*"
```

**Files:** none (global tool).

## Tests

This is a tool on your machine, not code in the repo, so there is no automated test at any level.

**Unit** — none.

**Integration** — none.

**End-to-end** — none. Manual check: `dotnet ef --version` prints `10.x`. The first real use is M1.5, which fails loudly if the tool is missing or mismatched.

**Done when:** `dotnet ef --version` prints a version starting with `10.`.
