# M2.1 — View models for browsing

**Goal:** Small classes that carry exactly what each page needs. Views never receive entities directly.

**Steps**

Create these in `src/CraigsClone.Web/ViewModels/`.

`PagedResult.cs` — one page of results plus paging info.

```csharp
namespace CraigsClone.Web.ViewModels;

public class PagedResult<T>
{
    public required IReadOnlyList<T> Items { get; init; }
    public required int Page { get; init; }
    public required int PageSize { get; init; }
    public required int TotalCount { get; init; }

    public int TotalPages => (int)Math.Ceiling(TotalCount / (double)PageSize);
    public bool HasPrevious => Page > 1;
    public bool HasNext => Page < TotalPages;
}
```

`HomeVm.cs` — for the home page.

```csharp
public class HomeVm
```

## Tests

**Unit** — `Unit/ViewModels/PagedResultTests.cs`. Pure math, use `[Theory]` with `[InlineData]`:

| TotalCount | PageSize | expected TotalPages |
|---|---|---|
| 0 | 20 | 0 |
| 1 | 20 | 1 |
| 20 | 20 | 1 |
| 21 | 20 | 2 |
| 40 | 20 | 2 |

And for 41 items, page size 20: page 1 has `HasPrevious == false, HasNext == true`; page 2 has both true; page 3 has `HasPrevious == true, HasNext == false`.
