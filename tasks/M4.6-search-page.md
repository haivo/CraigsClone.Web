# M4.6 — Cross-category search page

**Goal:** `/search?q=bike&city=austin` searches every category in Austin. Without `city`, it searches everywhere.

**Steps**

In `IListingService` add:

```csharp
Task<PagedResult<Listing>> SearchAsync(SearchFilterVm f, int? cityId, int? categoryId);
```

Implement by starting from `db.Listings.Include(City).Include(Category)`, applying `cityId` and `categoryId` filters only when not null, then `Query(...)` and `ToPagedAsync(...)` from M4.2.

In `ListingsController`:

```csharp
[HttpGet("search")]
public async Task<IActionResult> Search(SearchFilterVm filter)
```

- If `filter.City` is set, look up the city by slug (404 if unknown). Same for `filter.Category`.
- Call `SearchAsync`, return a `SearchVm` (filter + results + optional city + optional category).

Views:

- `Views/Listings/Search.cshtml` — heading (`search in Austin` or `search everywhere`), `_SearchForm`, the result rows, `_Pager`.
- Update `_ListingRow.cshtml` to take a `showCityAndCategory` flag; when true, print the city and category names on the row.
- Add a link `search all of {city}` to `/search?city={slug}` on the city page.
