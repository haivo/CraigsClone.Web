# M5.4 — Run the whole suite and fill the gaps

**Goal:** Every test written in M0.8 to M5.3 passes together, in one command, and there's a short script for it.

Tests were written task by task, so this task is a sweep rather than a pile of new files.

**Steps**

1. Run each category on its own and fix anything red:

   ```powershell
   dotnet test --filter Category=Unit
   dotnet test --filter Category=Integration
   dotnet test --filter Category=E2E
   ```

2. Run everything together: `dotnet test`. Watch for tests that pass alone but fail together. The usual cause is a test asserting on a total count instead of on its own rows (see the rules in [01-testing-approach.md](01-testing-approach.md)).

3. Check every test class has a `[Trait("Category", ...)]`:

   ```powershell
   Get-ChildItem tests -Recurse -Filter *Tests.cs | Select-String -NotMatch 'Trait\("Category"' -List
   ```

   That prints files missing the trait. Fix them.

4. Create `test.ps1` in the repo root:

   ```powershell
   param([ValidateSet("unit","integration","e2e","all")] $what = "all")
   $filter = switch ($what) {
     "unit"        { "--filter Category=Unit" }
     "integration" { "--filter Category=Integration" }
     "e2e"         { "--filter Category=E2E" }
     default       { "" }
   }
   dotnet test $filter
   ```

5. Count them. If a category is far lighter than expected, go back to the task files and see what was skipped.

   Actual count at the end of M5.3: **231** tests, 91 unit, 114 integration, 26 end-to-end. Unit runs in seconds; the full suite in about two minutes, almost all of it container startup and browser tests.

6. Speed. Any test that inserted many rows in a loop (25 separate scopes each) now uses `TestData.AddListingsAsync`, which does it in one round trip. Prefer it for anything above a handful of rows.

**Files**

- `test.ps1` (new)
- any test file that needed fixing

## Tests

**Unit** — all of `Unit/` is green with `.\test.ps1 unit`, and it finishes in under a few seconds.

**Integration** — all of `Integration/` is green with `.\test.ps1 integration`, with Docker running.

**End-to-end** — all of `E2E/` is green with `.\test.ps1 e2e`, with Docker running and Chromium installed.

**Done when:** `.\test.ps1` (everything) is green twice in a row.
