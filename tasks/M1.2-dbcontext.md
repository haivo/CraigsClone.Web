# M1.2 — AppDbContext

**Goal:** The EF Core class that maps the entities to tables and sets the database rules (unique slugs, price precision, index).

**Steps**

Create `src/CraigsClone.Web/Data/AppDbContext.cs`:

```csharp
using CraigsClone.Web.Models;
using Microsoft.EntityFrameworkCore;

namespace CraigsClone.Web.Data;

public class AppDbContext(DbContextOptions<AppDbContext> options) : DbContext(options)
{
    public DbSet<City> Cities => Set<City>();
    public DbSet<Category> Categories => Set<Category>();
    public DbSet<Listing> Listings => Set<Listing>();

    protected override void OnModelCreating(ModelBuilder b)
    {
        b.Entity<City>(e =>
        {
            e.Property(x => x.Name).HasMaxLength(80).IsRequired();
            e.Property(x => x.Slug).HasMaxLength(60).IsRequired();
            e.HasIndex(x => x.Slug).IsUnique();
        });

        b.Entity<Category>(e =>
        {
            e.Property(x => x.Name).HasMaxLength(80).IsRequired();
            e.Property(x => x.Slug).HasMaxLength(60).IsRequired();
            e.Property(x => x.Group).HasConversion<string>().HasMaxLength(20);
            e.HasIndex(x => x.Slug).IsUnique();
        });

        b.Entity<Listing>(e =>
        {
            e.Property(x => x.Title).HasMaxLength(120).IsRequired();
            e.Property(x => x.Description).IsRequired();
            e.Property(x => x.Price).HasPrecision(10, 2);
            e.Property(x => x.Neighborhood).HasMaxLength(80);
            e.Property(x => x.ContactEmail).HasMaxLength(254).IsRequired();
            e.HasIndex(x => new { x.CityId, x.CategoryId, x.CreatedAt }).IsDescending(false, false, true);
            e.HasOne(x => x.City).WithMany().OnDelete(DeleteBehavior.Restrict);
            e.HasOne(x => x.Category).WithMany().OnDelete(DeleteBehavior.Restrict);
        });
    }
}
```

Notes:

- `HasConversion<string>()` stores the group as text ("ForSale") so it's readable in psql.
- The composite index is what makes the browse page fast: city, then category, then newest first.
- `Restrict` means you can't delete a city or category that still has listings.

Then extend `Integration/PostgresFixture.cs` from M0.8 so tests can get a context. Add:

```csharp
public AppDbContext CreateContext() =>
    new(new DbContextOptionsBuilder<AppDbContext>().UseNpgsql(ConnectionString).Options);

public async Task InitializeAsync()
{
    await _pg.StartAsync();
    await using var db = CreateContext();
    await db.Database.EnsureCreatedAsync();   // M1.5 changes this to MigrateAsync
}
```

## Tests

**Unit** — `Unit/Data/AppDbContextModelTests.cs`. You can inspect the EF model without any database: build a context with `UseNpgsql("Host=x")` (never opened) and read `db.GetService<IDesignTimeModel>().Model`. Not `db.Model`: that's the trimmed runtime model and it throws when you ask for index direction.

- `Listing.Price` has precision 10 and scale 2.
- `Listing.Title` max length is 120.
- `City.Slug` index is unique; `Category.Slug` index is unique.
- `Listing` has an index on `CityId, CategoryId, CreatedAt`.
- `Category.Group` column type is text, not integer (`GetColumnType()` or the value converter is non-null).

**Integration** — `Integration/Data/AppDbContextTests.cs`, `[Collection("postgres")]`:

- Inserting two cities with the same slug throws `DbUpdateException` (the unique index is really in the database, not just in the model).
- Saving a listing with `Price = 12.345m` reads back as `12.35m` or `12.34m` (Postgres rounds to two decimals). Proves the precision reached the column.
- Saving a listing with a `DateTime.Now` (Kind Local) `CreatedAt` throws. Documents point 4 of [00-before-you-start.md](00-before-you-start.md).

**End-to-end** — none. No page touches the database yet.
